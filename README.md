# Андрей Кучугурин — Советник

Одностраничный сайт. Статика без сборки: открыть `index.html` в браузере
или выложить папку на любой хостинг как есть.

| Файл | Что в нём |
|---|---|
| `index.html` | разметка и все тексты страницы |
| `ak.css` | стили; решения по вёрстке описаны в комментариях |
| `ak.js` | шапка, меню на телефоне, появление блоков, якоря |
| `assets/fonts/` | Spectral и Golos Text (OFL), подключает `ak-fonts.css` |
| `hero-andrey.jpg` | фото первого экрана, 4:5 |
| `about-andrey.jpg` | фото в блоке «Кто такой Советник», 4:5 |

Контакты (Telegram, телефон) стоят в одном месте — блок `#contact`
в конце `index.html`. Остальные кнопки страницы ведут к нему.

## До запуска

- [x] Домен prosovetnik.online: `canonical`, `og:url`, `og:image` (og-image.jpg, 1200×630), favicon, robots.txt, sitemap.xml.
